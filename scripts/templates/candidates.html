Calibration

Every hash in the baseline was unresolved when its name was proposed. The ones carrying a name today are the only scored predictions this exercise gets, so they are worth reading run by run beside the modelled noise. This is not a blind test. Those campaigns read the sweep, so a hash enters the denominator because someone chose to work it; what the number measures is how often a worked proposal was the spelling that survived attestation, not how often a candidate picked at random is right.
